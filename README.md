# Persona Stream

Локальное приложение для Windows: личность ИИ-персонажа, выборочное чтение X, меняющиеся интересы, память об авторах и журнал автоматических действий. Модель работает на отдельном сервере Ollama.

## Запуск и подключение

Установи Node.js 24.11 или новее, затем выполни `npm ci` и запусти `Start.cmd` на Windows. Панель: **http://127.0.0.1:4317**.

1. Открой **Подключение**, укажи адрес Ollama, точное имя установленной модели и аккаунт X. В разделе **Личность** задай персонажа. Эти данные сохраняются только в `data/config.json`.
2. В поле «Способ подключения» выбери **Существующий Chrome** и сохрани настройки.
3. В нужном профиле Chrome открой `chrome://extensions`, включи режим разработчика и загрузи распакованное расширение из папки `chrome-extension` этого проекта. В панели есть её полный путь.
4. Открой X под указанным аккаунтом, нажми значок расширения **Persona Stream → Подключить текущую вкладку**.
5. В панели нажми **Получить код подключения** и введи его в открывшейся вкладке соединителя. Оставь её и вкладку X открытыми.
6. Нажми в панели **Проверить вход**. Приложение сравнит открытый аккаунт с настройкой.
7. Выбери **Читать X → Обзор → Прочитать одну пачку**, чтобы проверить чтение ленты.
8. Для автоматических действий выбери **Автономно в X → Запустить**.

Расширение работает только с выбранной вкладкой X в существующем профиле Chrome и не читает cookies или пароли. Можно переключиться на отдельный профиль браузера; вариант Chromium требует предварительного `npm run browser:install`.

Кнопка **Остановить** останавливает агента. Закрытие вкладки не завершает приложение. `Stop.ps1` завершает приложение. После перезапуска агент сам не начинает работу.

## Режимы

- **Учебная лента:** настроенная модель, вымышленные посты, отдельная память. Действия только симулируются.
- **Читать X:** чтение и запоминание без публикаций и реакций.
- **Автономно в X:** чтение и включённые в настройках внешние действия.

## Механика

Источник постов — только вкладка **For you / Для вас** на главной странице X. Программа не ищет посты по ключевым словам. Модель получает первые 240 знаков каждого поста. Из 8 превью выбирается до 3 постов для полного чтения. Оценка учитывает интерес, любопытство, новизну, текущие увлечения и отношение к автору. Полный текст оценивается заново. Интерес, согласие и желание ответить — разные величины.

Вес интереса меняется небольшим шагом в сторону ценности прочитанного и любопытства. Повторение темы ослабляет сигнал. Закреплённые темы сохраняют вес. Новая тема появляется после минимум 3 ценных публикаций от 2 авторов с одинаковым названием обнаруженного интереса.

Память автора содержит заметки, цитаты, источники, время, уверенность и изменения отношения. Придуманная цитата не меняет отношение к автору. При следующем чтении извлекается до 5 подходящих воспоминаний. Для генерации политического ответа личная карточка адресата не используется.

По умолчанию: первые действия после 5 полных чтений; до 20 лайков, 5 ответов, 2 подписок и 1 своего поста за последние 24 часа; пауза между действиями от 180 секунд; не более одного ответа автору за 24 часа. Свои посты — после 30 чтений. Лимит сеанса — 30 полных чтений.

Действия записываются до отправки. Если нажатие состоялось, а подтверждение не получено, агент останавливается. Проверь результат в X и отметь его в разделе **Действия**. Автоматического повтора нет. Остановка не отменяет уже отправленное действие.

## Данные и проверка

`data/config.json` — адрес и имя модели, описание персонажа, приватные заметки, интересы и аккаунт; `data/memory.sqlite` — память X; `data/demo.sqlite` — учебная память; `data/x-browser/` — отдельный браузерный профиль; `logs/` — журналы. Все эти каталоги исключены из Git. Экспорт из панели содержит настройки и память, поэтому его тоже храни вне репозитория.

`npm test` — тесты памяти, обучения, лимитов, остановки, защиты от повторной отправки и HTTP-интерфейса. `npm run check` — проверка синтаксиса.

В журнале сеанса записываются выбранные посты, причины выбора, намерение выполнить действие и этапы браузерного соединителя. Подробности каждой записи раскрываются нажатием **Подробности**. Раздел **Действия** показывает текст ответа, целевой пост и итог.

После изменения файлов расширения открой `chrome://extensions` в нужном профиле Chrome, нажми **Обновить** у Persona Stream, затем снова подключи вкладку X. Уже открытая вкладка соединителя продолжает работать со старой версией до переподключения.

Версия 0.2.4 работает с текстом и доступным текстовым контекстом ветки. Изображения, видео, внешние статьи, личные сообщения, репосты и отписки пока не обрабатываются. Посты длиннее 10 000 знаков не читаются полностью. При изменении разметки X приложение может остановиться с ошибкой.

Аккаунт предполагается обозначенным как ИИ с вымышленным персонажем. X запрещает автоматизацию сайта вне API и автоматические лайки; возможны ограничения аккаунта. Приложение не обходит CAPTCHA и проверки доступа.

Код приложения написан отдельно. Архитектурные ориентиры: [xinfluencer](https://github.com/lordx64/xinfluencer), [Person Memory](https://github.com/Hubujiu/person-memory), [elizaOS](https://github.com/elizaOS/eliza).
